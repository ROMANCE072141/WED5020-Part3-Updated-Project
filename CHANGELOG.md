# Changelog

## Part 1 — Initial setup
- Created the five core HTML pages: home, about, products, enquiry and contact.
- Added CSS, JavaScript and images folders.
- Added initial README documentation.

## Part 2 — CSS and responsive design
- Added external shared styles for typography, colours, backgrounds, spacing and content layout.
- Used Flexbox for the header/navigation and CSS Grid for product/content cards.
- Added borders, rounded corners, shadows, hover/focus states and responsive tablet/mobile layouts.
- Added responsive image sizing and initial enquiry-form validation.

## Part 3 — JavaScript functionality and SEO
- Added page-specific title tags, meta descriptions, keywords, author, robots metadata and semantic page structure.
- Added descriptive image alternative text, internal navigation links and lazy loading for images.
- Added a responsive mobile navigation toggle and current-page navigation indicator.
- Added an accessible accordion for mission, vision and values on the About page.
- Added live product search and category filtering, including a no-results message.
- Added an image lightbox using the HTML dialog element.
- Added HTML5 and JavaScript validation to the enquiry form, automatic product selection from product links, EmailJS email submission, and success/error messages.
- Added HTML5 and JavaScript validation to the contact form, EmailJS email submission, and success/error messages.
- Added an illustrative embedded Google Maps search and external map link.
- Added CSS transitions, a reveal animation, reduced-motion support and a back-to-top button.
- Added `robots.txt` and `sitemap.xml`.
- Updated README with Part 3 implementation details, test instructions, limitations and references.
- Added visible notes that example email/telephone values and the map location are placeholders.
